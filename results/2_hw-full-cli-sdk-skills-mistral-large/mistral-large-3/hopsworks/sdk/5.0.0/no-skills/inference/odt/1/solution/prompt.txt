The directory data/ contains scoring requests (data/requests.csv) and stored account profiles (data/profiles.csv); see data/schema.md.
Each request carries request-time parameters (its coordinates) that must be combined with the stored profile via an ON-DEMAND transformation — a feature computed at request time, not precomputed:
  - distance_deg = sqrt((request_lat - home_lat)^2 + (request_lon - home_lon)^2), rounded to 6 decimal places;
  - score = base_score - 0.1 * distance_deg (using the rounded distance), rounded to 6 decimal places.
Produce a feature table named `scored9c0a6e`, version 1, on the platform, with record key `request_id` and exactly these columns: request_id, account_id, distance_deg, score. One row per request.
Make the table's features available for low-latency lookup as well (online/real-time access), where the platform distinguishes the two.
