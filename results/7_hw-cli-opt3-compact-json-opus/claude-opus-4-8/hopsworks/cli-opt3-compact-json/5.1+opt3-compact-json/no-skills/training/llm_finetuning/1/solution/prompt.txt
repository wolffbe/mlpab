The directory data/ contains a base character-level language model checkpoint (data/base_model.npz: bigram logits and vocab), a fine-tuning corpus (data/finetune.txt), a held-out evaluation set (data/eval.txt) and a provided, fully deterministic fine-tuning script (data/finetune_model.py) that reads all three from its working directory and writes finetuned_model.npz plus metrics.json ({"eval_loss": ..., "base_eval_loss": ...}). Do not modify the script or its hyperparameters; run it as-is.
Run the fine-tune AS A JOB ON THE PLATFORM — named `ftjob8025df` — not locally on this machine.
Then register the fine-tuned model in the platform's model registry as `ftmodel8025df`, version 1, attaching the metrics from the job's metrics.json to the registry entry, with the fine-tuned model file as the model's content.
Finally write submission/answers.json as:
    {"job_name": "ftjob8025df", "model_name": "ftmodel8025df", "eval_loss": <metrics.json eval_loss>, "base_eval_loss": <metrics.json base_eval_loss>}
