The directory data/ contains account feature profiles (data/features.csv: account_id, f1, f2, f3, f4) and a lookup list (data/lookup_keys.txt — one account_id per line).
Load the profiles into a feature table named `profiles44b75e`, version 1, on the platform, with record key `account_id`, and enable ONLINE / low-latency access for it.
Then retrieve the feature vector for EACH key in data/lookup_keys.txt THROUGH the online/low-latency read path (not by re-reading the CSV or the offline store), and write submission/answers.json as:
    {"vectors": {"<account_id>": [f1, f2, f3, f4], ...}}
with the feature values as loaded (floats, in the order f1, f2, f3, f4), one entry per lookup key.
