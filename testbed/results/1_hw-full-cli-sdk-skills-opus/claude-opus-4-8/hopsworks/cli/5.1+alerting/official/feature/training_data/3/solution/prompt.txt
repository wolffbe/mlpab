The directory data/ contains feature data for customer accounts:
  - data/transactions.csv
  - data/profiles.csv
  - data/activity.csv
  - data/account_health.csv
  - data/transactions_late.csv (a later export of transactions rows that arrived after the initial export — same schema, part of the same data)
  - data/labels.csv (account_id, label_time, churned)
  - data/schema.md (column documentation)

Produce a versioned training dataset named `churntrainingc6990d`, version 1, on the platform, with exactly these columns: account_id, label_time, amount, balance, credit_score, tier, sessions_7d, health_score, churned. One row per row of labels.csv.
For each (account_id, label_time) in labels.csv, every feature value must be the MOST RECENT value from its source table at or before label_time — values with event_time after label_time must not be used, in any table. `event_time` and `label_time` are epoch milliseconds. Join on account_id.
